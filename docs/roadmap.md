# Plan de versiones

## 0.1.0 — Base local

- Indexador local de instalaciones.
- Interfaz retro con búsqueda, filtros y orden.
- Lanzamiento por URI para Steam.
- Actualización manual y preparación para tarea nocturna.

## 0.2.0 — Lanzadores locales

- Lanzamiento directo para Epic, Ubisoft Connect, EA y Xbox/Microsoft Store.
- Carátulas locales y favoritos.
- Estado de disponibilidad por launcher.

## 0.3.0 — Biblioteca personal

- Integraciones autorizadas con las plataformas que lo permitan.
- Distinción entre comprado, instalado, oculto y desinstalado.
- Datos opcionales de tiempo de juego.

## 1.0.0 — Aplicación de escritorio

- Empaquetado como aplicación de Windows.
- Acceso directo y actualizaciones controladas.
- Configuración desde la propia interfaz.
